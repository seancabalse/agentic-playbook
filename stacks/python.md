## Stack: Python

- **Version and tooling**: one Python version, pinned in `.python-version` and `requires-python` and used in CI. Use `uv` for environments, dependencies and running tools (`uv sync`, `uv add`, `uv run pytest`). Commit `uv.lock`. Never `pip install` into the system or a shared interpreter.
- **Project layout**: `pyproject.toml` is the single place for metadata and tool config (start from `${CLAUDE_PLUGIN_ROOT}/templates/python/pyproject.toml`). Use a `src/<package>/` layout, so tests run against the installed package rather than the working folder. Tests live in `tests/`, mirroring the package.
- **Lint and format**: `ruff check` and `ruff format`, with the rule set in `pyproject.toml`. Fix the code, not the config: a `# noqa` needs the rule code and a reason.
- **Types**: annotate every public function and module boundary. Run `mypy --strict` (or `pyright` in strict mode) in CI on `src/` and `tests/`. Avoid `Any`; `cast()` and `# type: ignore[code]` need a comment saying why. A library ships `py.typed`.
- **Boundaries**: parse external input once, at the edge, into typed models (pydantic or `msgspec` for I/O and config; `dataclasses(frozen=True, slots=True)` for internal values). Inside, pass typed values, never raw `dict`s. Validate settings at startup (`pydantic-settings`); the process exits with a clear message when something is missing. `.env.example` lists the names only.
- **Errors**: one exception hierarchy per package, with a stable `code` on each class, and HTTP or CLI exit mapping in one place. Never `except Exception: pass`. Catch narrowly, re-raise with `raise … from err`, and keep tracebacks out of user-facing output.
- **Time**: timezone-aware `datetime` only (`datetime.now(UTC)`). Use `zoneinfo.ZoneInfo` for IANA zones, `date` for calendar dates, and the shared time module for zone maths, never ad-hoc offsets. Naive datetimes fail review.
- **Async**: pick one model per service. In async code, never call blocking I/O: use async clients, or `asyncio.to_thread` for unavoidable blocking calls. Every outbound call has a timeout. Use structured concurrency (`asyncio.TaskGroup`) rather than stray `create_task`.
- **Logging**: the standard `logging` module, or `structlog` for JSON. Get loggers per module with `logging.getLogger(__name__)`; libraries never configure the root logger. Log structured fields with a request or job id, never personal content or secrets. No `print` outside CLIs.
- **Data access**: parameterised queries only (SQLAlchemy 2.x Core/ORM, or the driver's placeholders); never build SQL with f-strings. Migrations through the project's tool (Alembic, Django migrations); never edit one that has merged.
- **Security**: no `eval`/`exec`/`pickle` or `yaml.load` on untrusted input (`yaml.safe_load`). Call `subprocess` with an argument list, never `shell=True` with interpolated input. Use `secrets` for tokens, not `random`. Run `pip-audit` (or `uv` with an advisory check) in CI, and `ruff`'s `S` (bandit) rules.
- **Performance**: measure before optimising (`cProfile`, `py-spy`). Use generators for large streams, and batch database and network calls. A C extension or Rust module is a dependency decision (`vet-dependency`): check its wheels for every target platform.
- **Tests**: `pytest`, with plain `assert`s and fixtures in `conftest.py`. Use `pytest-asyncio` or `anyio` for async, `hypothesis` for property-based tests of rules (time, parsing, money), and Testcontainers or Docker Compose for real databases. Never call live third-party APIs: use `respx` or `responses`, or test the pure module. Coverage is a signal, not a target.
- **Packaging and running**: entry points in `[project.scripts]`. Containers use a slim base, a non-root user, `uv sync --frozen --no-dev`, and `PYTHONDONTWRITEBYTECODE=1` / `PYTHONUNBUFFERED=1`. Notebooks are for exploration only: logic that matters moves into the package with tests.
- **Commands** (fill in "This project"): `uv sync`, `uv run ruff check .`, `uv run ruff format --check .`, `uv run mypy`, `uv run pytest`, `uv run pip-audit`.
